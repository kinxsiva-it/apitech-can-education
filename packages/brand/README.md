# APITech brand assets

Customer-provided API TECH logo, shared by Education and Admin through `@apitech/brand`.

- Original JPG copied without image edits to `src/assets/apitech-logo.jpg`.
- Website asset: `src/assets/apitech-logo-transparent.png`, extracted using the built-in imagegen tool. Original JPG remains unchanged.
- Use `BrandLogo` and set `--apitech-logo-width` on its container for responsive sizing.
- Keep the original lettering and colors; the shared component uses the PNG alpha channel without a CSS background.
- Vite handles the asset URL in each app and embeds the image in the standalone Education export.
- This customer asset does not carry an open-source license from this project.

Image edit brief: remove the flat black background and empty negative spaces; preserve API TECH lettering, orange/silver/blue artwork and layout, with transparent empty areas and opaque artwork. No redesign or added text.
