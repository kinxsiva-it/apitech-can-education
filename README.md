# APITech CAN Education

Browser-first CAN Bus education simulator foundation using React, Vite, strict
TypeScript, Tailwind CSS and Zustand. Supabase and React Router are installed
for future integration. No backend credentials are required.

## Development

Use Node.js 22.12+.

```powershell
npm install
npm run dev
npm run build
npm run lint
```

Keep node_modules, dist, local credentials and customer UI reference HTML out of Git.
Simulation, teaching content and UI features will be added in separate commits.
